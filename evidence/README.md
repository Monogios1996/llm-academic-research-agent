# Execution and testing evidence

This directory contains chronological evidence collected during development,
including automated test milestones, live-provider runs, integration failures,
remediation notes, persistence verification, the fixed 12-case evaluation, and
the Streamlit demonstration path.

The evidence was recorded as the corresponding functionality was developed
rather than reconstructed retrospectively. This preserves both successful runs
and genuine failures that led to code changes.

The main chronological records are under `test-results/`. Local generated
runtime files such as SQLite checkpoints, JSON run logs, evaluation reports,
and approved research-package exports remain gitignored; reviewed outcomes are
summarised in the committed evidence notes instead.
